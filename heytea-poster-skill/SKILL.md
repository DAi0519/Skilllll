# 喜茶风海报 Skill

把用户主题附加到一份已批准的原始 Prompt 母版。原始母版是不可改写的数据，不是供总结的参考文章。

## 执行流程

1. 判断用户要的是成品海报还是提示词；“做、生成、画一张”默认生成成品图，“写/给我 prompt”才只输出提示词。
2. 从第一行到最后一行完整读取 `references/handwritten-poster.prompt.en.json`。
3. 把母版内容逐字、逐字段、按原顺序作为生成指令的第一部分。禁止翻译、摘要、压缩、润色、重排、补写或删除任何字段和值。
4. 在母版之后追加独立的 `USER_BRIEF`，只记录用户明确给出的主题、标题、短句、日期、地点、品牌或情绪。用户原文必须逐字保留。
5. 用户没有提供某项内容时保持缺省，让母版自身的 `workflow` 与 `dynamic_variables` 处理；禁止根据个人偏好新增视觉规则、比例、构图、颜色、负面提示词或禁用项。
6. 生成前执行完整性检查：母版七个顶级字段及其所有嵌套字段和值必须全部出现且顺序一致；任何缺失都必须停止并重新读取母版。
7. 用户要成品图时，把“完整母版 + USER_BRIEF”原样提交给可用的图像生成工具；用户要提示词时，完整输出同一份组合，不改写成自然语言摘要。

## 权威母版

完整读取 `references/handwritten-poster.prompt.en.json`。它是唯一生成依据，不得使用摘要或个人经验替代。

## 质量门槛

- 先保证母版完整和用户文字准确，再执行生成。
- 不允许“保留大意”“提炼视觉 DNA”或“等价改写”；效果依赖原始层级、措辞和重复强调。
- 生成成品图后检查是否出现错字、伪字、多余文字或与原始母版冲突的视觉元素。
- 若文字准确性不足，明确指出并建议减少文字或二次编辑；不要声称图中文字已准确。
- 最终只交付用户需要的结果，不附带内部分析、配方全文或同步信息。

## 母版维护

- `references/` 只放经过字节级一致性校验的原始 Prompt 母版。
- 修改母版时必须与权威来源重新做字节级校验；不得提炼、删减或改写。
